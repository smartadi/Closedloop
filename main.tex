\begin{abstract}
Mesoscale brain dynamics have been linked to a wide range of perceptual, cognitive and motor functions.
However, establishing causal links between mesoscale dynamics and behavior remains challenging, because it requires not only perturbing these dynamics but also precisely shaping them.
Here we show that closed-loop optogenetic inhibition can steer cortical activity in real time toward a reference below baseline, using feedback from the ongoing activity it controls.
The trial-averaged response of a cortical readout next to the stimulated site is approximately linear and, within a session, time-invariant.
On this basis, we design a linear feedback controller that tracks a reference.
It holds activity at the reference more accurately than open-loop stimulation in all 15 sessions from 4 mice and reduces trial-to-trial variability, consistent with disturbance rejection.
Controller performance depends on brain state: feedback removes more of the error that accompanies movement, whereas its error grows with slow-wave-like delta-band (1--4\,Hz) activity.
Predicting the disturbance on each trial from the opposite hemisphere, we show that feedback partially rejects it.
In one mouse tracking a time-varying reference, preview cancels the phase lag of the cortical response, whereas feedback reduces error and variability.
Finally, in a simulated replay of recorded trials with a constant reference, a model-predictive controller using a linear model of cortex and the laser lowers the error left by feedback by about 40\%.
Together, these results show that approximately linear, time-invariant trial-averaged dynamics can be used to control regional cortical activity, and that the error left under control is informative about brain state.
\end{abstract}


\section*{Significance Statement}
We introduce a closed-loop control framework that steers cortical activity toward a reference. 
Using wide-field calcium imaging, we read out activity at one cortical site in real time and use it to set optogenetic inhibition delivered next to it, which can only lower that activity. 
Closed-loop stimulation tracks the reference more accurately than open-loop stimulation and reduces trial-to-trial variability across sessions and animals.
The error that remains under feedback depends on cortical state around stimulation, and feedforward preview corrects the phase lag when tracking time-varying references. 
Finally, a linear model of the opposite hemisphere predicts much of the spontaneous activity in the controlled region (median held-out $R^2 = 0.76$), which lets us estimate the disturbance the controller rejects on each trial.
